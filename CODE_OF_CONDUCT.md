# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Participants are expected to follow its standards in project spaces and when representing the project.

To report a conduct concern privately, contact the maintainer through the contact method on [@rakrsh's GitHub profile](https://github.com/rakrsh). If that is unavailable, use [GitHub's abuse reporting process](https://support.github.com/contact/report-abuse). Do not report conduct concerns in public issues.
